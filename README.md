# roborally-java
A Java implementation of RoboRally, built step by step to learn object-oriented design, TCP networking, JavaFX, automated testing, and game AI.

## Build

With JDK 22 installed, run the following command from the project root:

```bash
./mvnw clean compile
```

On Windows, use `.\mvnw.cmd clean compile`.

## Run the desktop client

From the project root, start the JavaFX client:

```bash
./mvnw javafx:run
```

On Windows, use `.\mvnw.cmd javafx:run`.
